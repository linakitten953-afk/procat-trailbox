# Прокат оборудования «ТрейлБокс»

Веб-приложение для автоматизации процесса аренды оборудования (спорт, туризм, строительство).

## Основные возможности
- **Клиент:** просмотр каталога с фильтрами, бронирование на выбранные даты, личный кабинет с историей аренд.
- **Менеджер:** выдача и приём оборудования, фиксация состояния, автоматический расчёт штрафов за просрочку и повреждения.
- **Администратор:** управление каталогом товаров, тарифами, сотрудниками, а также просмотр статистики и аналитики.

## Стек технологий
- **Backend:** C# (ASP.NET Core, .NET 7)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **База данных:** SQLite (Microsoft.Data.Sqlite)

## Как запустить проект локально
1. Установите [.NET SDK 7]. (или новее).
2. Склонируйте репозиторий или скачайте проект.
3. Откройте папку с проектом в VS Code.
4. В терминале выполните команду:
   dotnet run
5. Перейдите в браузере по адресу: http://localhost:5080

При первом запуске автоматически создастся файл базы данных rental.db с тестовыми данными.
